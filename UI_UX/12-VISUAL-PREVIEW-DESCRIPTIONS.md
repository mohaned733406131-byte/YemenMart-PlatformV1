## CS-CK-001: Checkout (7 Steps)

### Step Overview

| Step | Name | Fields |
|------|------|--------|
| 1 | Address | Name, Phone, Governorate, Area, Details |
| 2 | Shipping | Standard/Express/Store Pickup |
| 3 | Payment | E-Wallet (Wallet Only) |
| 4 | Review | Order Summary, Confirmation |
| 5 | Processing | Order Confirmation |
| 6 | Payment Success | Transaction Complete |
| 7 | Order Confirmed | Tracking Number |

## Arabic RTL Layout Notes

1. **Direction**: All layouts mirror horizontally for RTL
2. **Navigation**: Logo on right, navigation flows right-to-left
3. **Text Alignment**: Arabic text aligns right by default
4. **Icons**: Directional icons (arrows) flip horizontally
5. **Progress Bars**: Fill from right to left
6. **Carousels**: Scroll from right to left
